# Fixture Provenance

- `modal-shape-*.json` freezes the key, omission, wrapper, and ordering
  behaviour derived from the legacy handlers and their concrete graph DTOs.
  Values are illustrative and are not parity values.
- `survey-shape.json` freezes the response key and omission behaviour derived
  from the legacy survey handler and response structs. Values are illustrative
  and are not parity values.
- These shape fixtures were generated from the checked-in legacy Go contracts,
  not by treating a local Memgraph dataset as an independent value oracle.
  Their executable proof is the MR2/MR4 canonical-JSON handler test suite.
- Relational value assertions are independently seeded in the MR1/MR2/MR4
  integration tests. Expected values are written directly from the seed
  contract, never generated by querying the implementation under test.
- The stub and depot cases are relational row-population assertions: the graph
  shape has no depot row, while an FSS stub has the same station DTO shape with
  zero/empty optional values.
