================================================================
ACTIVITY REQUIREMENTS (Control Points)
================================================================

These are the "Control Points" shown on the tug-of-war display on the
map. Personally-earned merits for rank are usually four times greater
than these, but multipliers can vary.

- To start Acquisition Conflict: 36,000 control points
- To Acquire a system: 120,000 control points (including the above)
- To reinforce a system to Fortified from minimum Exploited: 350,000 control points
- To reinforce a system to Stronghold from minimum Fortified: 650,000 control points
- To reinforce a system to maximum Stronghold from minimum Stronghold: 1,000,000 control points

================================================================
WEEKLY TASKS
================================================================

Each player is given five tasks at the start of the Powerplay cycle,
granting a significant number of bonus personal merits. Players starting
the cycle at rank 40 or higher get an additional five tasks (total ten).

Weekly tasks may specify particular systems to be carried out in; these
will normally be near to the player's start-of-cycle location. To reduce
the chance of being given an impossible task, it is best to start the
week near a border with another Power.

Weekly tasks are mostly optional and there is no penalty for not
completing them - a new set will be given the following week regardless.
The initial set of five tasks given when joining a Power is required to
unlock rank progression (but will never specify systems, so should
always be possible).

================================================================
SYSTEM TYPES
================================================================

- Friendly System: any Exploited, Fortified or Stronghold of your Power.
- Unfriendly System: any Exploited, Fortified or Stronghold of any
  other Power.
- Target System: the system being affected.
- Supporting System: a Fortified system within 20 LY of an Acquisition
  System, or a Stronghold system within 30 LY.
- Reinforcement System: any friendly system EXCEPT the capital/HQ
  system.
- Undermining System: any unfriendly system EXCEPT the capital/HQ
  system.
- Acquisition System: any neutral system within range of one of your
  Supporting Systems.
- Unoccupied System: any neutral system, whether in range or not.
- Acquisition Conflict System: a neutral system in which two or more
  Powers (including yours) have reached the Conflict threshold.

================================================================
STRONGHOLD CARRIERS
================================================================

Most Undermining methods do not work at all in systems containing a
Stronghold Carrier. This is noted with a "-SC" (doesn't work) or "+SC"
(works) entry in the Undermining column above.

of them stack together.

  Name | Documented? | Affects | System Type | Direction | Magnitude |

================================================================
WORKED EXAMPLES
================================================================

Example 1: Ship scan as a Kaine pledge in a Reinforcement system in the
HIP enclave that has recently been Undermined below the threshold:

  Baseline value: 3 control points
  - Control point modifier: ethos bonus at +50%
  - Control points earned: 4.5, rounded up to 5
  - Merits modifier: -35% for reinforcement
  - Merits modifier: +35% for emergency defence
  - Merits modifier: +30% for system having had recent heavy undermining
  - Standard merits multiplier: 4x
  - Total merits multiplier: 5.2x → 26 Merits earned

Example 2: Antal pledge carrying out a 1 million credit donation
mission to an enemy Fortified system:

  Baseline value: 27 control points
  - Control point modifiers: System Strength Penalty, System Rank
    Penalty and Beyond Frontline Penalty apply. Total effect highly
    system specific. Assuming a total of -50% for this example.
  - Control points earned: 14
  - Merits modifier: +15% for standard undermining
  - Standard merits multiplier: 4x
  - Total merits multiplier: 4.6x → 64 Merits earned

================================================================
SUMMARY
================================================================

In general:
- Reinforcement gets MERIT (but not control point) penalties.
- Undermining usually gets CONTROL POINT penalties which are often
  substantially larger than its merit bonuses.
- Acquisition is a neutral "baseline" with no inherent merit/CP modifier.
